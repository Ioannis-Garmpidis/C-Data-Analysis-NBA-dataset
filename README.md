# NBA Data Analysis – C++ Project

## Περιγραφή
Η παρούσα εργασία υλοποιεί μια εφαρμογή ανάλυσης δεδομένων σε γλώσσα C++, η οποία διαβάζει δεδομένα από αρχείο CSV, εφαρμόζει καθαρισμό ελλιπών ή μη έγκυρων τιμών και υπολογίζει βασικά στατιστικά μεγέθη και συσχετίσεις.  
Στόχος του έργου είναι η προσομοίωση ενός πλήρους data analysis pipeline με έμφαση στη σωστή δομή κώδικα και στη μέτρηση απόδοσης.

## Dataset
Το dataset προέρχεται από στατιστικά NBA παικτών και περιλαμβάνει περισσότερες από 10.000 εγγραφές με πολλαπλές αριθμητικές μεταβλητές (π.χ. ηλικία, πόντοι, ασίστ, ποσοστά χρήσης).

## Λειτουργικότητα
Η εφαρμογή εκτελεί τα εξής στάδια:
- Φόρτωση δεδομένων από CSV αρχείο
- Καθαρισμός δεδομένων (μετατροπή missing/invalid τιμών σε NaN)
- Υπολογισμός στατιστικών δεικτών (mean, median, variance)
- Υπολογισμός πίνακα συσχέτισης (Pearson correlation)
- Εξαγωγή αποτελεσμάτων σε αρχεία αναφοράς
- Μέτρηση χρόνου εκτέλεσης κάθε σταδίου
